# 둔기 남자 대난투 — 기획 메모 (새 세션 시작용)

> 「둔기 남자」(로그라이크, 바탕화면 `해머버서커` 폴더)에서 캐릭터·무기·타격감만 가져와 만드는 **1:1 PvP 대결 게임**. 완전히 새 파일로 만든다. 원본 게임 파일은 건드리지 않는다.
> 새 세션에서는 "이 메모 보고 1단계 만들어 줘"라고 하면 된다. 참고용 원본은 `바탕화면\해머버서커\hammer_dev.html`.

## 확정된 것
- **이름**: 둔기 남자 대난투 (임시)
- **장르**: 쿼터뷰(원본과 같은 시점) 원형 경기장 1:1 대결
- **승리 조건**: 링 아웃. 상대를 경기장 밖으로 날리면 목숨 -1, **목숨 3개**. 맞을수록 **피해 %**가 쌓이고, %가 높을수록 넉백이 커진다(스매시브라더스 방식). 장외로 떨어지면 % 초기화 후 중앙 위쪽에서 다시 등장(잠깐 무적).
- **무기 4종** (각자 고름):
  - 🔨 망치: 기본형. 묵직한 한 방, 차지 = 부채꼴 슬램.
  - 🔨🔨 쌍망치: 빠른 연타로 % 쌓기, 대시 2회, 차지 = 팽이 회전.
  - 🏏 빠따(몽둥이): 3연타(좌→우→내려치기), 차지 = 홈런 스윙(풀차지 '딱!' + 슬로모션). 장외 마무리 담당. 빗나가면 빈틈 큼.
  - 🍳 프라이팬: 휘두른 직후 저스트 가드(상대 공격 무효 + 반격 '깡!'), 차지 = 팬 방패. 상대 차지 공격에는 약하게.
  - 상성 목표: 쌍망치 연타 < 프라이팬 가드 < 망치·빠따 차지 < 쌍망치 기동력.
- **공통 조작**: 이동, 휘두르기(클릭/J), 꾹 눌렀다 떼기 = 차지 공격, 대시(Space/Shift), 저스트 회피(공격이 닿기 직전 대시).
- **원본에서 가져올 것**: 둔기 남자 캐릭터 그림·움직임(drawPlayer), 무기 그림(artHammer·artTwin·artBat·artPan, wc 컨텍스트 방식), 효과음 sfx·브금 구조, impact·addText·화면 흔들림·멈칫(freeze)·슬로모션(slow), 그림자(shadow), 쿼터뷰 변환(SX/SY, T=.72).
- **뺄 것**: 몹, 레벨업·특성, 보스·4기사·용, 젬, 하트, 무기 해금.

## 대결 방식
1. **온라인 1:1** (주력): 아티팩트의 `room` 기능 사용.
   - 조건: **Claude에 로그인한 사람 중 이 아티팩트에 초대받은 사람만** 접속 가능. 공개 링크·비로그인은 접속 불가(혼자 하는 봇 모드만 됨). 친구는 공유 메뉴에서 이메일로 초대.
   - 구조: 대기실(lobby) → 방 코드로 `room.join(name)` → 둘이 모이면 시작.
   - 동기화: 각자 자기 캐릭터를 직접 움직이고 `presence`로 상태(위치·방향·공격 중·무기·%·목숨·순번 카운터)를 1초 약 30번 보낸다(4KiB 이하, 절대값). 맞았는지는 **때린 쪽 화면 기준**으로 판정해 presence에 "타격 번호 + 넉백 방향·세기"를 실어 보내고, 맞은 쪽이 그 번호를 처음 보면 넉백을 적용한다(신호가 빠질 수 있으니 같은 값을 몇 프레임 유지).
   - 이벤트 topic(emit)은 기본이 편집자 전용이라 쓰지 않거나 `topics: {...: "interact"}`로 열기. presence는 누구나 보낼 수 있어서 presence 중심으로 설계.
   - 실제 렉·신호 유실은 아직 시험해 본 적 없음 → 2단계에서 시제품으로 확인.
2. **한 컴퓨터 1:1** (덤): 키보드 나눠 쓰기 (P1 WASD+F/G, P2 방향키+숫자패드 등).
3. **봇 연습** : 혼자 테스트·공개 링크용.

## 만드는 순서
1. **1단계**: 경기장(원형, 가장자리 표시) + 내 캐릭터 + 무기 4종 기본 공격·차지·대시 + 봇 상대 + 피해 %·넉백·링 아웃·목숨 3개·승패 화면. 메뉴에서 무기 고르기.
2. **2단계**: 온라인 방(대기실, 방 코드, 상대 동기화, 타격 판정 전달) → 친구 초대해서 실제 렉 확인.
3. **3단계**: 한 컴퓨터 1:1, 3판 2선승, 무기 상성 밸런스, 연출·브금 다듬기.
