# 해머 버서커 작업 메모 (이어서 작업용)

> 게임 이름은 **망치 남자**로 바꿨다(화면 제목·탭 이름). 파일 이름과 폴더 이름은 그대로다.

> 계획했던 A~I와 추가 밸런스 요청까지 모두 반영됐다. 이후 수정은 이 메모와 hammer_dev.html, build_public.py를 주고 요청하면 된다.

## 파일
- **hammer_dev.html**: 원본(개발자용). 모든 수정은 이 파일에 한다. ` 키로 치트 패널이 열린다.
- **hammer.html**: 배포용. `python3 build_public.py`로 dev 파일에서 치트(패널 HTML·CSS·코드, P.god)를 지워 만든다. 직접 고치지 않는다.
- **bosses.js**: 일반 보스 6종 그림 함수(시안 확정본). feather, drawBird2, 보스 6종 모두 게임에 들어갔다.
- **build_public.py**: 배포판 생성 스크립트. 파일을 열 때 encoding='utf-8'이 지정돼 있지 않아 윈도우에서 직접 실행하면 한글 때문에 오류가 날 수 있다.

### B. 최종 보스 구조 변경 ✅ 완료
- 14:00에는 **항상 용기사**가 나온다. 용기사는 **못 잡은 기사의 기술만** 쓴다(잡은 기사의 기술은 못 씀). 4기사를 다 잡았으면 용 기술만 쓰는 약한 용기사가 된다.
- **히든 보스 고대의 용**: 4기사를 다 잡은 상태로 용기사를 쓰러뜨리면, 용기사가 타던 금빛 용의 빛이 꺼지면서 검게 흑화해 고대의 용으로 각성한다. 흑화 연출을 넣는다.
- 고대의 용은 히든 최종 보스로 강화한다. 체력을 올리고 새 패턴을 넣는다(예: 하늘을 덮는 어둠 운석, 맵을 가르는 거대 화염 브레스, 날갯짓 폭풍으로 밀어내기). 기존 불 뿜기, 비행 후 내리찍기, 운석은 유지한다.
- 4기사를 다 못 잡은 상태로 용기사를 잡으면 그대로 클리어한다.
- **트로피 변경**: 🏆 = 용기사 격파, 👑 = 고대의 용 격파. 설명 문구도 바꾼다.

### E. 차지 슬램 개편 ✅ 완료
- **일반 차지 슬램**은 부채꼴로 바꾼다. 조준 방향(마우스, 모바일은 아래 G)으로 나가고, 살짝 모으면 60°, 풀차지면 180°까지 넓어진다. 길이도 같이 늘어난다. 모으는 동안 바닥에 부채꼴 범위를 표시하고, 균열과 충격파도 부채꼴 방향으로 뻗는다.
- **대지 분쇄(quake) 특성 재구성**: 모든 레벨에서 범위 +20, 피해 +12%(5레벨에서 약 1.6배). 추가로:
  - Lv3: **하이퍼 차지** 해금
  - Lv4: 하이퍼 모으는 시간 1초 → 0.6초
  - Lv5: 하이퍼 충격파 3번 → 5번, 쿨타임 6초 → 4초
- **하이퍼 차지**: 풀차지 후 계속 누르고 있으면(기본 1초 더) 발동한다. **전 범위 360°**다.
  - 모을 때: 주인공 주변에 붉은 금빛 오라가 휘몰아치고 화면 가장자리가 어두워진다.
  - 찍는 순간: 주변 적을 끌어당겼다가 거대 폭발, 충격파 3번 연속.
  - 쿨타임 6초.

### F. 쿨타임 표시 UI ✅ 완료
- 화면 오른쪽 아래에 대시, 슬램, 하이퍼 차지 원형 아이콘을 둔다. 쿨타임 동안 어둡다가 시계 방향으로 밝아지고, 남은 초를 숫자로 표시한다.
- 다시 쓸 수 있게 되면 아이콘이 반짝이고 짧은 소리가 난다. 하이퍼 차지가 준비되면 주인공 발밑에 금빛이 잠깐 번진다.
- 대지 분쇄 3레벨 전에는 하이퍼 아이콘을 자물쇠로 표시한다.
- 모바일: 🔨 버튼 테두리와 대시 버튼에 쿨타임 게이지를 표시한다.
- 기존 왼쪽 위 텍스트("대시 OK", "슬램 OK")는 정리한다.

### G. 모바일 조준 ✅ 완료
- 🔨 버튼을 누르면 차지가 시작된다. 누른 채 드래그하면 그 방향으로 부채꼴이 돌아가고, 버튼 위에 방향 화살표를 표시한다.
- 떼면 그 방향으로 슬램이 나가고, 짧게 눌렀으면 그 방향으로 휘두른다.
- 끌지 않고 탭만 하면 가장 가까운 적을 자동으로 노린다.
- 하이퍼 차지는 전 방위라 방향과 무관하다.

### H. 주인공 팔다리 + 역동적인 모션 ✅ 완료
- 주인공(뿔 투구 쓴 주황 공)에 작은 팔다리를 붙인다. 기사들처럼 데포르메 스타일로 하고, 팔이 망치를 쥔다.
- **휘두르기**: 직전에 몸을 뒤로 젖혔다가 크게 돌리고, 끝나면 반동으로 살짝 더 돈다. 망치 끝에 잔상 궤적을 남긴다.
- **차지 슬램**: 모으는 동안 웅크렸다가, 떼는 순간 뛰어올라 망치를 머리 위로 들고 내리꽂는다. 착지할 때 몸이 납작하게 눌린다.
- **하이퍼 차지**: 더 높이 뛰어 한 바퀴 돌며 내리찍는다.
- **대시**: 몸이 길게 늘어나고 잔상이 3~4개 남는다.
- **걷기**: 이동 방향으로 기울고 통통 튀며, 다리가 움직인다.
- **적**: 날아갈 때 빙글빙글 회전하고 땅에 튕긴다.
- **카메라**: 하이퍼 차지나 보스 격파처럼 강한 타격에 순간 확대(줌 펀치)를 넣는다.

  - 용기사전: 웅장한 보스곡
  - 고대의 용: 어둡고 무거운 최종곡
- M 키로 음소거할 때 브금도 함께 꺼진다. 브금만 따로 켜고 끄는 옵션이 있으면 좋다.

## 구현 메모 (4~8단계 + 추가 요청)
- **추가 밸런스 요청 반영**
  - 삭제: 드랍 폭탄(💣 픽업 드랍), 폭발 처치(연쇄 폭탄) 특성, 주인공 🌊충격파 특성. (booms·bombAll·waves 코드는 남아 있음. waves는 검기사 환영이 씀)
  - 적 탄: 탄속 배율 BSP=0.68(이동·수명 모두), 맞을 때 피해 ×1.35. 고리형 탄막 개수와 겹 수를 줄였다(창기사 불 고리 10발, 갑수 가시 8발, 포자 9발, 서리 7발, 망령 7~9발, 마왕 가시 10~13발, 나선 간격 0.15초, 날갯짓 바람 칼날 7~9발).
  - 4기사: 50% 이하에서 e.half(분노 배너). 검기 1회→2회, 불 고리 1겹→2겹, 3연속 화살 1회→2회, 망치 기사 충격파 1겹→2겹. 각각 데미지는 올렸다. 용기사는 항상 2회.
  - 데미지 시간 비례: 기사 kMul()=min(2.2, .45+time/380). 일반 보스는 bMul()=1+max(0,time-200)/700을 hurtMul과 새로 만든 탄·운석·장판 dmg에 곱한다.
  - 적 수: 스폰 묶음 min(4, 1+time/150), 간격 max(.3, .9-time*.003), 최대 MAXE()=min(130, 50+time*.18), 포위 웨이브 최대 26. 파티클 상한 520.
  - 최종 보스 불: 불 파티클 p.fl(lighter 합성, 흰색→노랑→주황→빨강), 입가 빛, 바닥 그을음 그라데이션. fire 효과음을 겹으로 만들고 간격 0.11초, roar 강화.
- **초반 완화(사용자 요청)**: hpMul()은 3분까지 1+time/120(3분에 2.5배), 3~5분 사이에 원래 곡선(1+t/45+(t/160)²)으로 부드럽게 합류.
  - 슬라임 왕: 체력 1400, 속도 60, 접촉 12. 큰 점프 충격파 0겹(분노 1), 피해 16. 연속 점프 2번(분노 3), 피해 10. 침 4발 1회(분노 5발 2회), 피해 8. 분열 조건은 최대 체력 8% 이상 한 방, 간격 2.2초, 죽을 때 분열 4마리. 쿨타임 1.45배.

- **보스 충격파 사거리 축소**: 기사·용기사 knightSlam 충격파 수명 1.3→0.67초(최대 약 250), 일반 보스 bLand 1.2→0.9초(최대 약 300). 속도·데미지는 그대로, 끝에서 더 빨리 흐려짐.
- **회복 밸런스(흡혈 의존 줄이기)**: 흡혈은 처치당 0.5×Lv지만 초당 1.5×Lv까지만(P.vampB 예산). 재생 레벨당 1.2/초. 하트 드랍 2.5%(자석 0.6%). 일반 보스·기사 처치 시 최대 체력 30% 회복. 레벨업마다 최대 체력 +5, 체력 10 회복.

- **연쇄 번개(chain, 기절 강타를 대체)**: 휘두르기가 적중하면 첫 적부터 190 이내 가장 가까운 적으로 0.035초 간격 튕김. 튕기는 수 5+5×Lv(Lv1 10명, Lv5 30명), 피해 P.dmg×(.5+.125×(Lv-1))(Lv1 50% → Lv5 100%). 쿨타임 11-Lv초(Lv1 10초 → Lv5 6초, P.chainCd), 쿨타임 UI에 🌩️ 아이콘 추가. chains 배열, fx 'bolt', zap 효과음. 망치 주위 전기 스파크 외형.

## 사용자 선호
- 요청하지 않은 작업(아티팩트 만들기 등)은 먼저 물어보고 진행한다.
- "이야기하자"고 하면 정리가 끝날 때까지 파일을 고치지 않는다.
- 큰 작업은 시안 이미지를 먼저 보여주고 확인받는다.
- 토큰 사용량을 신경 쓴다. 큰 작업은 예상 토큰(과 시간)을 알려준다. 단계마다 새 세션을 열기보다 한 대화에서 끝까지 진행하길 원한다.
- 개발자 치트는 배포판에 넣지 않는다. 수정은 dev 파일에 하고 build_public.py로 배포판을 만든다.
- 그림 스타일은 데포르메(머리 크고 굵은 외곽선, 그라데이션 음영). 용은 예외로 공들인 측면 그림이다.
