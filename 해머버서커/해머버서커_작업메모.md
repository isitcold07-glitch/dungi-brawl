## 파일
- **hammer_dev.html**: 원본(개발자용). 모든 수정은 이 파일에 한다. ` 키로 치트 패널이 열린다.
- **hammer.html**: 배포용. `python3 build_public.py`로 dev 파일에서 치트(패널 HTML·CSS·코드, P.god)를 지워 만든다. 직접 고치지 않는다.
- **bosses.js**: 일반 보스 6종 그림 함수(시안 확정본). feather, drawBird2, 보스 6종 모두 게임에 들어갔다.
- **build_public.py**: 배포판 생성 스크립트. encoding='utf-8' 지정 완료(윈도우에서도 실행 가능).
- **weapons_art.js**: 무기 그림 시안 원본. 망치·쌍망치·철퇴·프라이팬 그림은 게임에 들어갔다(ctx→wc). 몽둥이·신전 기둥 그림은 아직 이 파일에만 있다.

### B. 최종 보스 구조 변경 ✅ 완료
- 14:00에는 **항상 용기사**가 나온다. 용기사는 **못 잡은 기사의 기술만** 쓴다(잡은 기사의 기술은 못 씀). 4기사를 다 잡았으면 용 기술만 쓰는 약한 용기사가 된다.
- **히든 보스 고대의 용**: 4기사를 다 잡은 상태로 용기사를 쓰러뜨리면, 용기사가 타던 금빛 용의 빛이 꺼지면서 검게 흑화해 고대의 용으로 각성한다. 흑화 연출을 넣는다.
- 고대의 용은 히든 최종 보스로 강화한다. 체력을 올리고 새 패턴을 넣는다(예: 하늘을 덮는 어둠 운석, 맵을 가르는 거대 화염 브레스, 날갯짓 폭풍으로 밀어내기). 기존 불 뿜기, 비행 후 내리찍기, 운석은 유지한다.
- 4기사를 다 못 잡은 상태로 용기사를 잡으면 그대로 클리어한다.
- **트로피 변경**: 🏆 = 용기사 격파, 👑 = 고대의 용 격파. 설명 문구도 바꾼다.

### E. 차지 슬램 개편 ✅ 완료
- **일반 차지 슬램**은 부채꼴로 바꾼다. 조준 방향(마우스, 모바일은 아래 G)으로 나가고, 살짝 모으면 60°, 풀차지면 180°까지 넓어진다. 길이도 같이 늘어난다. 모으는 동안 바닥에 부채꼴 범위를 표시하고, 균열과 충격파도 부채꼴 방향으로 뻗는다.
- **대지 분쇄(quake) 특성 재구성**: 모든 레벨에서 범위 +20, 피해 +12%(5레벨에서 약 1.6배). 추가로:
  - Lv3: **하이퍼 차지** 해금
  - Lv4: 하이퍼 모으는 시간 1초 → 0.6초
  - Lv5: 하이퍼 충격파 3번 → 5번, 쿨타임 6초 → 4초
- **하이퍼 차지**: 풀차지 후 계속 누르고 있으면(기본 1초 더) 발동한다. **전 범위 360°**다.
  - 모을 때: 주인공 주변에 붉은 금빛 오라가 휘몰아치고 화면 가장자리가 어두워진다.
  - 찍는 순간: 주변 적을 끌어당겼다가 거대 폭발, 충격파 3번 연속.
  - 쿨타임 6초.

### F. 쿨타임 표시 UI ✅ 완료
- 화면 오른쪽 아래에 대시, 슬램, 하이퍼 차지 원형 아이콘을 둔다. 쿨타임 동안 어둡다가 시계 방향으로 밝아지고, 남은 초를 숫자로 표시한다.
- 다시 쓸 수 있게 되면 아이콘이 반짝이고 짧은 소리가 난다. 하이퍼 차지가 준비되면 주인공 발밑에 금빛이 잠깐 번진다.
- 대지 분쇄 3레벨 전에는 하이퍼 아이콘을 자물쇠로 표시한다.
- 모바일: 🔨 버튼 테두리와 대시 버튼에 쿨타임 게이지를 표시한다.
- 기존 왼쪽 위 텍스트("대시 OK", "슬램 OK")는 정리한다.

### G. 모바일 조준 ✅ 완료
- 🔨 버튼을 누르면 차지가 시작된다. 누른 채 드래그하면 그 방향으로 부채꼴이 돌아가고, 버튼 위에 방향 화살표를 표시한다.
- 떼면 그 방향으로 슬램이 나가고, 짧게 눌렀으면 그 방향으로 휘두른다.
- 끌지 않고 탭만 하면 가장 가까운 적을 자동으로 노린다.
- 하이퍼 차지는 전 방위라 방향과 무관하다.

### H. 주인공 팔다리 + 역동적인 모션 ✅ 완료
- 주인공(뿔 투구 쓴 주황 공)에 작은 팔다리를 붙인다. 기사들처럼 데포르메 스타일로 하고, 팔이 망치를 쥔다.
- **휘두르기**: 직전에 몸을 뒤로 젖혔다가 크게 돌리고, 끝나면 반동으로 살짝 더 돈다. 망치 끝에 잔상 궤적을 남긴다.
- **차지 슬램**: 모으는 동안 웅크렸다가, 떼는 순간 뛰어올라 망치를 머리 위로 들고 내리꽂는다. 착지할 때 몸이 납작하게 눌린다.
- **하이퍼 차지**: 더 높이 뛰어 한 바퀴 돌며 내리찍는다.
